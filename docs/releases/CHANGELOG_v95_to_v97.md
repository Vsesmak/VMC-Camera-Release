# Список изменений VMC 8.8 (v95 → v97)

☑️ **Умное восстановление светов + ARM64 NEON Soft-Highlight Knee (v97):** активирован нативный фикс пересветов и компенсация `2048` для всех устройств; потоковый NEON-алгоритм аккуратно сохраняет детали вывесок и источников света без потери ночной атмосферы
☑️ **TurboJPEG 3.2.1 NEON Vibrance & Cupertino SmartTone (v97):** подключена живая NEON-цветокоррекция без окрашивания серого асфальта и с защитой кожи + переключатель `Chroma Vibrance` рядом с `sRGB / DCI-P3` и режим `Cupertino SmartTone`
☑️ **Исправленная горячая смена Tonemap-кривых (v97):** нативные кривые `_StartTone` / `_StartGamma` реально применяются к кадру с корректным перезапуском сессии
☑️ **Sabre MTK и фиолетовый бейдж MediaTek (v97):** автоматическое определение MediaTek Dimensity/Helio, патч `libgcastartup.so` для Sabre MTK и отображение фиолетового статуса `Mediatek` в HUD
☑️ **Мгновенный старт, пообъективный Автокалибратор и новый UI (v97):** безусловное кэширование профиля холодного старта, пообъективные тумблеры, точность `0.00 µm`, статус `Применено / Сохранено`, автоперевод Dual-Corner HUD на все языки (`HudI18n`), новая иконка VMC и удаление фантомной кнопки `3.0` на K30 Pro Zoom
☑️ **Фиксы крашей Android 10 и Android 11 (v97):** безопасная совместимость `WindowInsets` (`whyred`, SDK 29) и `Build.SOC_MODEL` (`davinci`, SDK 30)
☑️ **Аппаратный автокалибратор и каталоги только для смартфонов (v96):** удаление устаревшего обучения по JPEG, 429 моделей шума и 45 цветовых матриц исключительно для мобильных сенсоров 2020–2026 гг.
☑️ **Универсальный AUX и ночная съёмка с Shasta (v95–v96):** 7 вариантов Package ID под одной подписью, защита от смаза и сохранение высокой микрорезкости (`Sharp > 1`)
